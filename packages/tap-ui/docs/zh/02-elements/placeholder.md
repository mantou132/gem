# `<tap-placeholder>`

占位组件，用于显示加载状态，行数和宽度可自定义。

## Example

<gbp-example name="tap-placeholder" src="https://esm.sh/@mantou/tap-ui/elements/placeholder">

```json
{
  "style": "width: 100%;",
  "type": "multi",
  "minLine": 3,
  "maxLine": 6
}
```

</gbp-example>

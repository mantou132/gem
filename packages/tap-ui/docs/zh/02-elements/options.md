# `<tap-options>`

选项列表组件，提供可选择的选项，标签和样式可自定义。

## Example

<gbp-example name="tap-options" src="https://esm.sh/@mantou/tap-ui/elements/options">

```json
{
  "style": "width: 240px;",
  "options": [
    { "label": "Option 1" },
    { "label": "Option 2" },
    { "label": "Option 3", "danger": true }
  ]
}
```

</gbp-example>

# `<tap-slider>`

Slider component. Allows users to select a value along a numeric range by dragging a thumb, with optional number input and vertical orientation.

## Example

<gbp-example name="tap-slider" src="https://esm.sh/@mantou/tap-ui/elements/slider">

```json
[
  { "value": 30 },
  { "value": 60, "editable": true },
  { "value": 40, "disabled": true }
]
```

</gbp-example>

# `<tap-switch>`

开关切换组件。支持多种语义色彩与禁用状态。

## Example

<gbp-example name="tap-switch" src="https://esm.sh/@mantou/tap-ui/elements/switch">

```json
[
  { "checked": true },
  { "checked": false },
  { "checked": true, "neutral": "positive" },
  { "checked": true, "neutral": "negative" },
  { "checked": true, "disabled": true }
]
```

</gbp-example>

# `<tap-badge>`

徽标与未读角标组件。支持数字、红点（dot）、最大上限数值以及包裹子元素定位。

## Example

<gbp-example name="tap-badge" src="https://esm.sh/@mantou/tap-ui/elements/badge">

```json
[
  { "count": "5" },
  { "count": "99" },
  { "count": "100", "max": 99 },
  { "dot": true },
  { "count": "NEW", "color": "positive" }
]
```

</gbp-example>

# `<tap-carousel>`

A horizontally swipeable carousel, each item has a label and content, the content can be a string or a `TemplateResult`.

## Example

<gbp-example name="tap-carousel" src="https://esm.sh/@mantou/tap-ui/elements/carousel">

```json
{
  "style": "width: 100%;",
  "label": "Featured",
  "items": [
    { "label": "Slide 1", "content": "Slide 1" },
    { "label": "Slide 2", "content": "Slide 2" },
    { "label": "Slide 3", "content": "Slide 3" }
  ]
}
```

</gbp-example>

# Internationalization

GemBook makes it easy to support multiple languages on the documentation site. The language code is displayed in the URL path: `/{lang}/path`.
Paths without a language code (e.g. `/` or old links) redirect to the language the user used last or the language preferred by the browser, or the default language.

## Enable internationalization

1. Use [`--i18n`](../002-cli.md#--i18n) or [`i18n`](../002-cli.md#i18n) to enable internationalization
2. Move the document to a folder named with the language code, for example:

```
docs/
├── en
│   ├── guide
│   │   ├── README.md
│   │   └── installation.md
│   ├── 003-about.md
│   └── README.md
└── zh
    ├── guide
    │   ├── README.md
    │   └── installation.md
    └── README.md
```

The default language is `en`, or the first language if there is no `en`, use [`fallbackLanguage`](../002-cli.md#fallbacklanguage) to specify it.

For language code support, please check [here](https://github.com/mantou132/gem/blob/main/packages/gem-book/app/lib/lang.json).
The text of the website itself (e.g. "Edit this page") supports English and Chinese, other languages use English.

## Untranslated documents

A document that only contains a title (frontmatter and `# Title`) is untranslated, the document of the same path in the default language is machine translated when building and a notice is displayed; if the translation fails, the original document is displayed.

## Directory name localization

By default, the directory name will be rendered directly in the sidebar. If you need to localize the directory name, there are two ways:
- Modify the directory name, for example, change `docs/zh/guide` to `docs/zh/002-指南`
- Add the file [`config.yml`](./004-metadata.md#dir) in the directory.

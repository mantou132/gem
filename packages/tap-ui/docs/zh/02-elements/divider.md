# `<tap-divider>`

分割线组件。用于划分不同内容区域，可添加文字标题及设置粗细。

## Example

<gbp-example name="tap-divider" src="https://esm.sh/@mantou/tap-ui/elements/divider">

```json
[
  {},
  { "innerHTML": "文本居中" },
  { "innerHTML": "靠左文本", "position": "start" },
  { "innerHTML": "加粗样式", "size": "medium" }
]
```

</gbp-example>

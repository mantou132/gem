# `<tap-badge>`

Badge and indicator component. Supports numbers, dot indicator, maximum count threshold, and positioning over wrapped content.

## Example

<gbp-example name="tap-badge" src="https://esm.sh/@mantou/tap-ui/elements/badge">

```json
[
  { "count": "5" },
  { "count": "99" },
  { "count": "100", "max": 99 },
  { "dot": true },
  { "count": "NEW", "color": "positive" }
]
```

</gbp-example>

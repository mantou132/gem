# `<tap-divider>`

Divider component. Used to visually separate content sections, optionally displaying text content and custom weight.

## Example

<gbp-example name="tap-divider" src="https://esm.sh/@mantou/tap-ui/elements/divider">

```json
[
  {},
  { "innerHTML": "Centered Text" },
  { "innerHTML": "Start Aligned", "position": "start" },
  { "innerHTML": "Medium Weight", "size": "medium" }
]
```

</gbp-example>

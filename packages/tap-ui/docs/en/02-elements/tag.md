# `<tap-tag>`

Tag component. Used for marking and categorizing items, supporting preset colors, solid/reverse styles, and closable action.

## Example

<gbp-example name="tap-tag" src="https://esm.sh/@mantou/tap-ui/elements/tag">

```json
[
  { "innerHTML": "Default Tag" },
  { "innerHTML": "Positive", "color": "positive" },
  { "innerHTML": "Informative", "color": "informative" },
  { "innerHTML": "Notice", "color": "notice" },
  { "innerHTML": "Negative", "color": "negative" },
  { "innerHTML": "Reverse", "color": "informative", "type": "reverse" },
  { "innerHTML": "Closable", "closable": true }
]
```

</gbp-example>

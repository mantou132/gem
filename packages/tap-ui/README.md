# TapUI

TapUI is the mobile-first UI package for Gem.

## Showcase

- [AgentDeck](https://agentdeck.xianqiao.wang) ([source](https://github.com/mantou132/AgentDeck)): control the coding agents on your computer from your phone
- [Showcase](https://github.com/mantou132/showcase): live demos of 30 TapUI components, a complete app to start from

## develop

```bash
# install dependencies
pnpm install
# test
pnpm test
# build watch
pnpm start
# development, view example and api
pnpm run docs
```

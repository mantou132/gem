# `<tap-button>`

移动端按钮组件。支持不同语义颜色、尺寸、幽灵/反色样式、圆角以及下拉菜单。

## Example

<gbp-example name="tap-button" src="https://esm.sh/@mantou/tap-ui/elements/button">

```json
[
  { "innerHTML": "主要按钮", "color": "normal" },
  { "innerHTML": "危险按钮", "color": "danger" },
  { "innerHTML": "取消按钮", "color": "cancel" },
  { "innerHTML": "反色样式", "type": "reverse", "color": "normal" },
  { "innerHTML": "圆角小按钮", "round": true, "small": true, "color": "normal" },
  { "innerHTML": "禁用状态", "disabled": true, "color": "normal" }
]
```
